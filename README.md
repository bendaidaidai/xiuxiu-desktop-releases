紫发、圆框眼镜、抱着小羊的小桌宠。适用于 Windows 10/11 x64，离线养成无需账号、Node.js 或 API 密钥。

## 安装

打开[最新版下载页面](https://github.com/bendaidaidai/xiuxiu-desktop-releases/releases/latest)，下载以 **x64-Setup.exe** 结尾的安装包，双击安装。安装后桌面会出现「咻咻桌宠」快捷方式。

## 更新

打开咻咻的小面板，在底部点击 **检查并更新**；也可以在系统托盘菜单点击同名按钮。有新版本时会显示下载进度，下载完成自动重启升级。任务、设置及聊天记录保留，未完成的番茄钟会暂停，等待你继续。

更新功能从 **0.3.0 安装版**开始提供。旧版需要先手动安装一次新版；免安装版不支持程序内升级。

## 0.4.3 新内容

- 直接在咻咻脚边查看心情、饱腹和精力；点饼干图标选择饼干、奶茶、水果、蛋糕或饭团。
- 喂食显示恢复数值，睡觉每 5 秒恢复 1 点精力，喂食不自动叫醒。
- 可选连接 Windows 本地模型聊天，发送即显示消息，回复逐步出现，可停止并保留原输入重试。
- Enter 发送，Shift+Enter 换行；修正 60 秒过早超时，并显示等待秒数。CPU 设备首次回复仍可能较慢。
- 原有摸头、戳脸、鼠标跟随、专注休息、久坐提醒、待办与小步骤监督继续可用。

## 本地模型聊天

安装包不包含 Ollama 或模型权重。自由聊天需要在运行桌宠的同一个 Windows 系统中安装 [Ollama](https://ollama.com/download/windows) 和模型，在“聊聊天 → 聊天连接”中检测、选择并启用。Mac 与 Windows 虚拟机各自的 `127.0.0.1` 指向不同系统。

未启用模型时，养成互动与状态短句仍可离线使用。启用模型后，聊天访问 Windows 本机的模型服务；主动检查更新时访问 GitHub。模型响应速度取决于电脑配置。

记录保存在自己的电脑上。此仓库只发布安装包、更新文件及使用说明，不存放开发源码、私人维护后台、聊天训练样本或任何朋友的使用记录。

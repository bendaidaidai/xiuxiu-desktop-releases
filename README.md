# 咻咻 · 小小桌宠

紫发、圆框眼镜、抱着小羊的小桌宠。适用于 Windows 10/11 x64，离线使用，无需账号、Node.js 或 API 密钥。

## 安装

打开[最新版下载页面](https://github.com/bendaidaidai/xiuxiu-desktop-releases/releases/latest)，下载以 **x64-Setup.exe** 结尾的安装包，双击安装。安装后桌面会出现「咻咻桌宠」快捷方式。

## 更新

打开咻咻的小面板，在底部点击 **检查并更新**；也可以在系统托盘菜单点击同名按钮。有新版本时会显示下载进度，下载完成自动重启升级。待办和设置保留，未完成的番茄钟会暂停，等待你继续。

更新功能从 **0.3.0 安装版**开始提供。旧版需要先手动安装一次新版；免安装版不支持程序内升级。

## 功能

- 摸头、戳脸、喂饼干，眼睛跟随鼠标。
- 可设专注与休息时长，久坐时轻轻提醒。
- 待办、小步骤和温和的进度监督。

平时不联网，只有主动点击更新时访问 GitHub 下载新版。记录保存在自己的电脑上。

此仓库只发布安装包和更新文件，不存放开发源码或任何朋友的使用记录。
